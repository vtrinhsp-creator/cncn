Đang chạy chế độ Cục bộ (Cùng trình duyệt)

Local Sync

Dữ liệu hiện chỉ đồng bộ giữa các tab trên cùng một máy tính. Để học sinh đăng nhập từ điện thoại / máy khác qua GitHub Pages, hãy dán cấu hình Firebase bên dưới.

1. Kết nối Firebase Firestore (Đồng bộ đa thiết bị)

Dán trực tiếp đoạn const firebaseConfig = { ... }; hoặc JSON sao chép từ Firebase Console.

Dùng để phân tách dữ liệu nếu bạn chạy nhiều lớp/môn trên cùng 1 Firebase.

Nên đổi khỏi 123456 trước khi đưa lên GitHub Pages.

Trợ lý AI Gemini (Phân tích đề & đáp án PDF)

Nhập Gemini API Key (miễn phí tại aistudio.google.com) để AI tự động đọc file PDF đề thi + PDF đáp án và tạo phiếu trả lời chuẩn xác. Khóa này chỉ lưu trên trình duyệt máy Giáo viên, KHÔNG nhúng vào file xuất cho học sinh.

2. Xuất file index.html cho GitHub Pages

Tải về tệp index.html đã nhúng sẵn cấu hình Firebase, App ID và mật khẩu Admin. Khi đưa tệp này lên GitHub Pages, mọi học sinh mở link trên điện thoại sẽ tự động kết nối ngay mà không cần cài đặt gì thêm.

Hướng dẫn thiết lập nhanh (Miễn phí)

  1. 1
    Truy cập console.firebase.google.com → Tạo dự án mới (Create a project).
  2. 2
    Vào Build → Firestore Database → Create database → chọn chế độ Start in test mode (chọn khu vực asia-southeast1 Singapore).
  3. 3
    Vào Build → Authentication → Get started → Sign-in method → bật Anonymous (Ẩn danh).
  4. 4
    Vào Project Settings (bánh răng) → Your apps → biểu tượng Web (</>) → đăng ký app và sao chép đoạn firebaseConfig dán vào ô bên trái → bấm Lưu & Kết nối Cloud ngay → bấm Xuất file index.html để đẩy lên GitHub Pages.
Mẹo kiểm tra trên 1 máy tính: Nếu chưa tạo Firebase, hệ thống vẫn tự động đồng bộ cục bộ giữa 2 tab trên cùng trình duyệt (1 tab đăng nhập admin, 1 tab đăng nhập hs01).
